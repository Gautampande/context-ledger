# v2.5.0 conversation map

## Purpose

`v2.5.0` turns one verified conversation archive into a small, inspectable evidence graph without an AI model. It combines five deliberately limited increments:

| Increment | Delivered capability |
| --- | --- |
| 2.1 | Deterministic event-node DAG derived from the immutable archive order. |
| 2.2 | Deliberate human-created forward-only evidence relationships. |
| 2.3 | A deterministic brief based only on graph facts and manual annotations. |
| 2.4 | A static, offline map viewer with no JavaScript or external requests. |
| 2.5 | Package persistence and verification for non-empty manual graph relationships. |

This is a graph **of one conversation**, not an AI-generated knowledge graph, a vector database, or a claim that every conversation is naturally a complex DAG.

## Graph model

Each archive event becomes a node containing only its stable event ID, sequence, role, and content hash. It does not duplicate or alter the canonical message text.

The tool creates a `next` edge for every adjacent pair of events. This is the normal linear conversation timeline. A person may add one of these manual relationship kinds:

- `supports`
- `clarifies`
- `supersedes`
- `depends_on`
- `answers`
- `relates_to`

Every manual edge must point from an earlier event to a later event. That rule keeps the graph acyclic and stops a manual relationship from rewriting chronology. The sidecar is checksum-bound to the archive ID and transcript hash, and its complete deterministic structure is rebuilt during verification.

The graph is stored beside the archive as `archive.aicx.json.graph.json`. It is derived local state, not part of the immutable transcript.

## Workflow

First create a graph. It has timeline edges only until you add manual relationships:

```sh
node src/cli.js graph-build \
  --archive archives/<archive-id>/archive.aicx.json

node src/cli.js inspect \
  --archive archives/<archive-id>/archive.aicx.json
```

Use IDs from `inspect` to connect evidence deliberately:

```sh
node src/cli.js graph-link \
  --archive archives/<archive-id>/archive.aicx.json \
  --from <earlier-event-id> \
  --to <later-event-id> \
  --kind supports

node src/cli.js graph-verify \
  --archive archives/<archive-id>/archive.aicx.json
```

Create a zero-AI inventory/brief and a static map viewer:

```sh
node src/cli.js graph-brief \
  --archive archives/<archive-id>/archive.aicx.json \
  --out conversation-brief.md

node src/cli.js graph-viewer \
  --archive archives/<archive-id>/archive.aicx.json \
  --query 'authentication decision' \
  --out conversation-map.html
```

Without `--query`, the viewer renders the most recent bounded set of event nodes. With a query, it uses the existing verified index when available and displays bounded adjacent evidence. The HTML includes no JavaScript, external resources, or executable attachments.

## Deterministic brief

`graph-brief` is intentionally an inventory, not a synthetic summary. It reports:

- Archive identity and capture metadata.
- Node and edge counts.
- Manual relationships with event IDs.
- Existing human annotations, grouped by their recorded type.
- Recent event IDs and roles.

It does not infer decisions, tasks, entities, causes, or hidden context. To create a high-quality natural-language summary or semantic retrieval result, use the separate optional BYOK AI workflow with explicit consent; that remains off by default.

## Portable packages

`context-ledger-package/1.1` retains a non-empty manual graph sidecar in a `.aicx` package. The package reader continues to accept the `1.0` package format from `v2.0.0`; those older packages simply restore without manual graph links.

The package still excludes raw provider pages, share URLs, arbitrary files, attachments, executable content, and AI results. See [the portable-package specification](v2.0.0-portable-package.md) for the stored-only ZIP boundary.

## Security and limits

- Historical conversation content, annotations, and manual links are untrusted data. A link is a human statement, not proof that its relationship is true.
- `graph-verify` checks the full graph against the canonical archive, including every timeline edge and manual-edge ordering.
- Unsupported fields, duplicate links, unknown event IDs, backward links, cycles, tampered hashes, oversized graph files, unsafe paths, and invalid JSON fail closed.
- The graph sidecar is limited to 16 MiB. The static viewer shows at most 80 nodes and bounds displayed event previews.
- Hashes detect modification relative to a trusted copy. They do not prove authorship, provider provenance, completeness, or legal admissibility.

## Non-goals

This release does not add a new provider adapter, automatic relationship inference, AI decisions/tasks/entities, embeddings, a database server, cloud sync, real-time collaboration, browser automation, or automatic import into another AI chat.
